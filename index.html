Modelos Recomendados para Ollama

Instala tus modelos favoritos ejecutando estos comandos en la terminal:

Llama 3.2 Vision (11B / 90B) 👁️

Modelo multimodal ideal para análisis de imágenes y descripción visual.

ollama run llama3.2-vision
Llava (7B / 13B) 👁️

Modelo vision popular para reconocer objetos, gráficos e imágenes.

ollama run llava
DeepSeek-R1 (1.5B / 7B / 8B)

Razonamiento lógico, resolución de algoritmos y matemáticas.

ollama run deepseek-r1:1.5b
Qwen 2.5 Coder (7B / 3B)

Especialista de alto rendimiento en programación.

ollama run qwen2.5-coder:3b
